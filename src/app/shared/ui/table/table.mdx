# Table

ตารางข้อมูล (Figma: Domain/Data Table, Domain/Table Header Cell, Domain/Table Cell) ใช้ HTML `<table>` ใส่ class `btfp-table` ไม่ต้องเขียน CSS ของตารางในหน้าเอง สไตล์อยู่ใน `src/styles.scss` หมวด 4

ทำไมไม่ใช้ `p-table` ของ PrimeNG: `p-table` ต้องส่งข้อมูลผ่าน binding (`[value]`) ซึ่งหน้าหุ่นจำลองใช้ไม่ได้ ตอนต่อ API จะเปลี่ยนเป็น `p-table` หรือใช้ `@for` กับ class เดิมก็ได้

<Canvas of={TableStories.Basic} />

## กฎ

1. แถวสูง 56px หัวตารางสูง 44px ข้อความบรรทัดเดียว ยาวเกินตัดด้วย ... ให้ใส่ `title` ที่ `<td>` เป็นข้อความเต็ม
2. กำหนดความกว้างคอลัมน์ที่ `<colgroup>` ด้วย class ของ Tailwind เช่น `<col class="w-[160px]" />` คอลัมน์ที่ไม่ใส่ความกว้างจะยืดเต็มที่เหลือ
3. ครอบด้วย `<div class="overflow-x-auto">` และใส่ความกว้างขั้นต่ำที่ตาราง เช่น `class="btfp-table min-w-[1574px]"` จอแคบจะเลื่อนซ้ายขวาได้ ไม่บีบคอลัมน์
4. สถานะใช้ `<btfp-status-tag status="..." />` ปุ่มท้ายแถวใช้ `<btfp-row-actions>` เท่านั้น
5. ไม่ต้องเขียน SCSS ของตารางในหน้า ถ้าต้องการสีเฉพาะของหน้า (เช่น ข้อความ "ยังไม่มอบหมาย" สีส้ม) ใส่ class ของหน้าเองได้

## ชนิดเซลล์

| Figma (Type) | class ที่ `<th>` และ `<td>` | หน้าตา |
| --- | --- | --- |
| text | ไม่ต้องใส่ | ชิดซ้าย Typography/Table หัวตาราง Body/S Medium |
| numeric | `btfp-table__num` | ชิดขวา ตัวเลขกว้างเท่ากัน |
| checkbox | `btfp-table__check` | คอลัมน์ 56px (`<col class="w-14" />`) ช่องอยู่กลาง |
| actions | `btfp-table__actions` | ชิดขวา คอลัมน์ 112px (`<col class="w-28" />`) |
| status | ไม่ต้องใส่ | ใส่ `btfp-status-tag` ในเซลล์ |
| text-2line | `btfp-table__2line` | 2 บรรทัด แถวสูง 64px ดูตัวอย่างด้านล่าง |

แถวที่เลือก ใส่ `class="is-selected"` ที่ `<tr>` (พื้นสีฟ้าอ่อน) ชี้เมาส์ที่แถวจะเป็นพื้นเทาอ่อน

ช่องเลือกในหน้าหุ่นจำลองใช้ `<input type="checkbox" class="btfp-checkbox">` หัวตารางที่เลือกบางแถวใส่ `is-indeterminate`

## ตัวอย่างโค้ด

```html
<div class="overflow-x-auto">
  <table class="btfp-table min-w-[880px]">
    <colgroup>
      <col class="w-14" />
      <col class="w-[130px]" />
      <col />
      <col class="w-[170px]" />
      <col class="w-[216px]" />
      <col class="w-28" />
    </colgroup>
    <thead>
      <tr>
        <th class="btfp-table__check"><input type="checkbox" class="btfp-checkbox is-indeterminate" aria-label="เลือกทั้งหมด" /></th>
        <th>เลขที่คำขอ</th>
        <th>ชื่อโครงการ</th>
        <th class="btfp-table__num">วงเงิน (บาท)</th>
        <th>สถานะ</th>
        <th class="btfp-table__actions">จัดการ</th>
      </tr>
    </thead>
    <tbody>
      <tr class="is-selected">
        <td class="btfp-table__check"><input type="checkbox" class="btfp-checkbox" checked aria-label="เลือก 2569/0042" /></td>
        <td>2569/0042</td>
        <td title="ศูนย์ทดสอบอุปกรณ์โทรคมนาคมชุมชน">ศูนย์ทดสอบอุปกรณ์โทรคมนาคมชุมชน</td>
        <td class="btfp-table__num">1,250,000.00</td>
        <td><btfp-status-tag status="review" /></td>
        <td class="btfp-table__actions"><btfp-row-actions actions="view,edit,delete" itemLabel="2569/0042" /></td>
      </tr>
    </tbody>
  </table>
</div>
```

ไฟล์ `.ts` ของหน้า import `BtfpStatusTag` และ `BtfpRowActions` จาก `shared/ui`
