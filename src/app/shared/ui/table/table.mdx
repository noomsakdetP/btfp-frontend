# Table

ตารางข้อมูล (Figma: Domain/Data Table, Domain/Table Header Cell, Domain/Table Cell) ใช้ HTML `<table>` ใส่ class `p-simple-table` ไม่ต้องเขียน CSS ของตารางในหน้าเอง สไตล์อยู่ใน `src/styles.scss` หมวด 4

ทำไมไม่ใช้ `p-table` ของ PrimeNG: `p-table` ต้องส่งข้อมูลผ่าน binding (`[value]`) ซึ่งหน้าหุ่นจำลองใช้ไม่ได้ ตอนต่อ API เปลี่ยนเป็น `p-table` แล้วใส่ class เดิมผ่าน `tableStyleClass` ดูหัวข้อ "ตอนต่อ API" ด้านล่าง

<Canvas of={TableStories.Basic} />

## กฎ

1. แถวสูง 56px หัวตารางสูง 44px ข้อความบรรทัดเดียว ยาวเกินตัดด้วย ... ให้ใส่ `title` ที่ `<td>` เป็นข้อความเต็ม
2. กำหนดความกว้างคอลัมน์ที่ `<colgroup>` ด้วย class ของ Tailwind เช่น `<col class="w-[160px]" />` คอลัมน์ที่ไม่ใส่ความกว้างจะยืดเต็มที่เหลือ
3. ครอบด้วย `<div class="overflow-x-auto">` และใส่ความกว้างขั้นต่ำที่ตาราง เช่น `class="p-simple-table min-w-[1574px]"` จอแคบจะเลื่อนซ้ายขวาได้ ไม่บีบคอลัมน์
4. **ชิดขวาเฉพาะจำนวนเงิน** (ใส่ `p-simple-table__money` ทั้ง `<th>` และ `<td>`) ตัวเลขอื่น เช่น จำนวนราย จำนวนโครงการ ร้อยละ คะแนน จำนวนวัน ชิดซ้ายเหมือนข้อความ
5. สถานะใช้ `<p-status-tag status="..." />` ปุ่มท้ายแถวใช้ `<p-row-actions>` เท่านั้น
6. ไม่ต้องเขียน SCSS ของตารางในหน้า ถ้าต้องการสีเฉพาะของหน้า (เช่น ข้อความ "ยังไม่มอบหมาย" สีส้ม) ใส่ class ของหน้าเองได้

## ชนิดเซลล์

| Figma (Type) | class ที่ `<th>` และ `<td>` | หน้าตา |
| --- | --- | --- |
| text | ไม่ต้องใส่ | ชิดซ้าย Typography/Table หัวตาราง Body/S Medium ใช้กับตัวเลขที่ไม่ใช่เงินด้วย เช่น จำนวนราย จำนวนวัน ร้อยละ คะแนน |
| numeric (จำนวนเงินเท่านั้น) | `p-simple-table__money` | ชิดขวา ตัวเลขกว้างเท่ากัน |
| checkbox | `p-simple-table__check` | คอลัมน์ 56px (`<col class="w-14" />`) ช่องอยู่กลาง |
| actions | `p-simple-table__actions` | ชิดขวา คอลัมน์ 112px (`<col class="w-28" />`) |
| status | ไม่ต้องใส่ | ใส่ `p-status-tag` ในเซลล์ |
| text-2line | `p-simple-table__2line` | 2 บรรทัด แถวสูง 64px ดูตัวอย่างด้านล่าง |

แถวที่เลือก ใส่ `class="is-selected"` ที่ `<tr>` (พื้นสีฟ้าอ่อน) ชี้เมาส์ที่แถวจะเป็นพื้นเทาอ่อน

ช่องเลือกในหน้าหุ่นจำลองใช้ `<input type="checkbox" class="p-native-checkbox">` หัวตารางที่เลือกบางแถวใส่ `is-indeterminate`

```html
<div class="overflow-x-auto">
  <table class="p-simple-table min-w-[880px]">
    <colgroup>
      <col class="w-14" />
      <col class="w-[130px]" />
      <col />
      <col class="w-[170px]" />
      <col class="w-[216px]" />
      <col class="w-28" />
    </colgroup>
    <thead>
      <tr>
        <th class="p-simple-table__check"><input type="checkbox" class="p-native-checkbox is-indeterminate" aria-label="เลือกทั้งหมด" /></th>
        <th>เลขที่คำขอ</th>
        <th>ชื่อโครงการ</th>
        <th class="p-simple-table__money">วงเงิน (บาท)</th>
        <th>สถานะ</th>
        <th class="p-simple-table__actions">จัดการ</th>
      </tr>
    </thead>
    <tbody>
      <tr class="is-selected">
        <td class="p-simple-table__check"><input type="checkbox" class="p-native-checkbox" checked aria-label="เลือก 2569/0042" /></td>
        <td>2569/0042</td>
        <td title="ศูนย์ทดสอบอุปกรณ์โทรคมนาคมชุมชน">ศูนย์ทดสอบอุปกรณ์โทรคมนาคมชุมชน</td>
        <td class="p-simple-table__money">1,250,000.00</td>
        <td><p-status-tag status="review" /></td>
        <td class="p-simple-table__actions"><p-row-actions actions="view,edit,delete" itemLabel="2569/0042" /></td>
      </tr>
    </tbody>
  </table>
</div>
```

ไฟล์ `.ts` ของหน้า import `StatusTag` และ `RowActions` จาก `shared/ui`

## ตอนต่อ API (สำหรับทีม dev)

หน้าหุ่นจำลองเขียนข้อมูลตายตัวทีละแถว ตอนต่อ API ให้เปลี่ยนเป็น `<p-table>` ของ PrimeNG แล้วใส่ class เดิมผ่าน `tableStyleClass` หน้าตาจะเหมือนหุ่นจำลอง (ทดสอบแล้ว แถว 56px หัวตาราง 44px ระยะและเส้นเท่าเดิม แถวที่เลือกพื้นฟ้าอ่อน ตัวอักษรสีปกติ ตั้งไว้ใน preset `datatable.row`)

| หุ่นจำลอง | ตอนต่อ API |
| --- | --- |
| `<table class="p-simple-table min-w-[...]">` | `<p-table [value]="rows()" dataKey="id" tableStyleClass="p-simple-table min-w-[...]">` |
| `<colgroup>` | ย้ายไปไว้ใน `<ng-template #colgroup>` |
| `<thead><tr>` | `<ng-template #header><tr>` |
| แถวตัวอย่างหลายแถวใน `<tbody>` | แถวเดียวใน `<ng-template #body let-row>` |
| ข้อความตายตัว `2569/0042` | `{{ row.requestNo }}` |
| `title="ข้อความเต็ม"` | `[title]="row.name"` |
| `1,440,000.00` | `{{ row.budget \| number: '1.2-2' }}` |
| `<p-status-tag status="review" />` | `<p-status-tag [status]="row.status" />` |
| `<input type="checkbox" class="p-native-checkbox">` ที่หัวตาราง | `<p-tableHeaderCheckbox />` |
| `<input type="checkbox" class="p-native-checkbox">` ในแถว | `<p-tableCheckbox [value]="row" />` และ `[(selection)]` ที่ `p-table` |
| `<tr class="is-selected">` | `<tr [pSelectableRow]="row">` (PrimeNG ใส่สถานะเลือกให้เอง) |
| `<p-paginator>` ใต้ตาราง | `[paginator]="true" [rows]="10"` ที่ `p-table` หรือคง `p-paginator` เดิมถ้าแบ่งหน้าที่ API |

class ของเซลล์ (`p-simple-table__money`, `__check`, `__actions`, `__2line`) และ `<col class="w-[...]">` ใช้ตามเดิมทุกตัว

```html
<div class="overflow-x-auto">
  <p-table [value]="rows()" dataKey="id" [(selection)]="selected" tableStyleClass="p-simple-table min-w-[880px]">
    <ng-template #colgroup>
      <colgroup>
        <col class="w-14" />
        <col class="w-[130px]" />
        <col />
        <col class="w-[170px]" />
        <col class="w-[216px]" />
        <col class="w-28" />
      </colgroup>
    </ng-template>
    <ng-template #header>
      <tr>
        <th class="p-simple-table__check"><p-tableHeaderCheckbox /></th>
        <th>เลขที่คำขอ</th>
        <th>ชื่อโครงการ</th>
        <th class="p-simple-table__money">วงเงิน (บาท)</th>
        <th>สถานะ</th>
        <th class="p-simple-table__actions">จัดการ</th>
      </tr>
    </ng-template>
    <ng-template #body let-row>
      <tr [pSelectableRow]="row">
        <td class="p-simple-table__check"><p-tableCheckbox [value]="row" /></td>
        <td>{{ row.requestNo }}</td>
        <td [title]="row.name">{{ row.name }}</td>
        <td class="p-simple-table__money">{{ row.budget | number: '1.2-2' }}</td>
        <td><p-status-tag [status]="row.status" /></td>
        <td class="p-simple-table__actions"><p-row-actions actions="view,edit,delete" [itemLabel]="row.requestNo" /></td>
      </tr>
    </ng-template>
  </p-table>
</div>
```

ไฟล์ `.ts` ของหน้า import `TableModule` จาก `primeng/table` และ `DecimalPipe` จาก `@angular/common` เพิ่ม
