# ระบบบริหารจัดการทุน กทปส. : ตัวอย่าง Front-end นำร่อง

Storybook นี้เป็นตัวอย่างให้ทีม dev ดูว่างานออกแบบใน Figma แปลงเป็น **Angular 21 + PrimeNG 21** อย่างไร

## มีอะไรบ้าง

| หมวด | เนื้อหา |
| --- | --- |
| Components | `btfp-*` component กลางของระบบ สร้างบน PrimeNG |
| Layout | Sidebar และ TopBar ของเจ้าหน้าที่ |
| Pages | หน้า B-01 ข้อเสนอโครงการ (มีข้อมูล และยังไม่มีข้อมูล) |

## หลักการที่ใช้

1. **ใช้ PrimeNG ก่อนเสมอ** ปรับหน้าตาผ่าน preset (`src/app/theme/btfp-preset.ts`) ไม่เขียน CSS ทับเอง
2. **ถ้า PrimeNG ไม่มี หรือมีแต่ต้องมีกฎเฉพาะของระบบ** ให้ห่อเป็น component `btfp-*` ใช้ชื่อ input แบบเดียวกับ PrimeNG (`severity`, `size`, `label`)
3. **สีและระยะห่าง** ใช้ token จาก Figma (`src/styles/_tokens.scss`) ห้ามใส่รหัสสีตรง ๆ
4. **ไอคอน** ใช้ Lucide ชุดเดียวกับ Figma: `<svg lucideIcon="eye" size="16"></svg>`
5. **วันที่** ใช้ `btfp-datepicker` เสมอ แสดง พ.ศ. แต่เก็บค่าเป็น ค.ศ.

## กฎของงานออกแบบที่โค้ดต้องตามด้วย

- แถวตารางสูง 56px ข้อความบรรทัดเดียว ยาวเกินให้ตัด
- ปุ่มท้ายแถวเรียง ดู แก้ไข ลบ และการลบต้องมีป๊อปอัปยืนยันทุกครั้ง
- ข้อความบนหน้าจอไม่ใช้ "—" และ "•" และไม่แสดงรหัสหน้าจอ (เช่น B-01)
